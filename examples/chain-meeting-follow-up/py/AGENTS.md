# AGENTS.md

Notes for people and coding agents working in this folder.

## What this is

Reason: direct | Act: no tools | Observe: raw | Decide: stop when done | Shape: prompt chain

Generated by LoopRig v3.6.7. Provider: Anthropic (Claude), model `claude-sonnet-5-5`.

## Run and test

- Run: `python agent.py "your task"`
- Check setup: `python agent.py --doctor`
- Regression suite: `python evals.py`

## Layout

- `agent.py`: the whole agent. Settings (MODEL, limits, SYSTEM) are at the top.
- `blueprint.json`: the design. Load it into LoopRig to change it, then regenerate.

## Tools

- None. The agent answers from the model alone.

## Conventions

- Never commit API keys. Use environment variables (see `.env.example`).
- Keep the turn and token limits while testing.
- Add an eval case for every failure you fix.
- Change behaviour by editing SYSTEM or the tool descriptions first. Reach for new code last.
